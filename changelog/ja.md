# 変更履歴

## [1.10.0]

紅の砂漠 2.06.00 に対応しました。

### 新機能

- **SaveUltimate は CDSE**(Crimson Desert Save Editor)になり、ロゴ・配色・フォントを一新しました。既定のテーマは CDSE オブシディアンで、以前の既定テーマはチャコールゴールドとして残っています。1.9.0 から更新した場合、実行ファイル名は次の更新まで `SaveUltimate.exe` のままで、その更新で `CDSE.exe` になります。エラーコードは `SU-` ではなく `CDSE-` で始まります(番号は同じです)。
- **編集履歴:** すべての編集が右側に並びます。項目を選ぶとその時点に戻り、先にも進めます（Ctrl+Y）。保存しても残ります。
- **アイテム → アイテムデータベース:** 通常のアイテムを1種類でも複数でもインベントリに追加。使う枠数を先に表示し、クエストアイテム・鍵・文書は追加できません。
- **インベントリ:** 装備のように重ならないアイテムの数量を増やすと、強化・ソケット・染色まで同じものがその数だけ増えます。
- **装備:** ソケットごとにペットの装備と同じく画像付きでギアを表示し、ギアの選択画面にはその装備に装着できるアビスギアだけを表示します。ギアごとに効果も表示します。能力値ギアは数値（攻撃力 +2、移動速度 +4%）、特殊効果ギアはその効果を表示し、カーソルを合わせるとゲーム内の説明が出ます。アイテム一覧からスロット列をなくしました。
- **ペット・乗り物メニューを新設:** ペット・馬・特殊な乗り物・馬車・船を追加・削除。船は基本の帆と大砲を備えています。削除すると身に着けている装備も削除されます。削除できない個体には理由（メイン、クエスト、荷物）を表示します。
- **ペット・乗り物 → 装備:** ペット・馬・特殊な乗り物・船・A.T.A.G.の装備を変更。船の大砲やA.T.A.G.の武器も可能です。装備は新しく作り、着けていた装備は消えます。
- **キャラクター → 染色:** 装備の部位ごとの色・染料・材質・汚れを確認。選んだ項目や、クリフ・ウンカ・デミアンの着用セットを、ファイルまたはメッセージに貼り付けられるコードとして書き出し、どちらからも読み込めます。項目ごとに場所・強化・今の染色を見て適用するアイテムを選ぶか、染色済みで新しく作れます。
- **生活 → ハウジング:** 自由建築の家全体を180°回転。

### 修正

- 表のセルを選ぶと文字が切れる問題を修正しました。
- 知識: レベルを適用するとレベル欄が空になる問題を修正しました。
- 傭兵をすべてゲームの傭兵一覧と同じ顔の肖像で表示します。画像のなかった46人も表示されます。
- スキル: アイテムを釣るを一覧から外しました。ゲームにまだ実装されていないようです。

### その他

- 装備・スキル・染色をまとめたキャラクターメニューを追加しました。
- ペット・乗り物・魚の画像が大きく背景なしになり、色ごとに区別できます。
- ペット・乗り物に家畜・釣った魚・内部データを表示しなくなりました。
- 詳細欄のボタンを減らして2つずつ並べ、まれな操作は⋯メニューに入れました。
- すべてのウィンドウがエディターのタイトルバーになりました。
- 同期したゲーム画像のディスク使用量が約3分の1になりました(590MB → 195MB)。同期も速くなりました。更新後の初回起動時に一度だけ同期し直します。

- **生活 → ハウジング:** DLCの区画の有効化、家の書き出し・読み込み。
- **NPC → ペット・乗り物:** 船の並べ替え。

- 更新内容がエディターの言語で表示されます。

- バックアップを復元すると、エディターの`backups/`フォルダーにもコピーが残ります。

### その他

- タブのヘルプを整理しました。バックアップ・復元のヘルプに、セーブごとに新しいバックアップ10個が残ることを追記しました。
